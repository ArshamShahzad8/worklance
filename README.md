# WORKLANCE

**Find talent. Get things done.**

WORKLANCE is a Flutter freelancing marketplace app where clients can post jobs and hire freelancers, and freelancers can offer services or apply to jobs with proposals. Built as a week-by-week internship project — this build is current through **Week 4**.


## Features

### Marketplace (services)
- Personalized home screen with featured and popular services
- Browse, search, and filter services by category, price, rating, and delivery time
- Sort by recommended, rating, price, or delivery speed
- Save/favorite services for later
- Freelancer profiles with bio, skills, rating, and reviews

### Job marketplace
- **Find Jobs** — browse job postings with search, category filters, and advanced filters (experience level, budget type, minimum budget, saved-only)
- **Post a Job** — clients can publish a job with title, description, category, skills, budget, and duration
- **Job Details** — full job description, budget, required skills, and client info
- **Submit Proposal** — freelancers apply with a cover letter, proposed rate, and estimated delivery time, pre-filled from the freelancer's own bio and matching skills
- **My Proposals** — track every proposal submitted
- **Proposal Status** — status and timeline (Submitted → Under Review → Shortlisted → Accepted/Rejected), with the option to withdraw
- Duplicate-submission protection — one proposal per job

### Freelancer & client tools
- **My Services** / **Create Service** — publish and manage services offered
- **My Freelancer Profile** — edit bio and skills, previewed the same way clients see it
- Editable user profile with client-side stats (jobs posted, total spent, payment verification)

### Auth
- Login and registration with full input validation
- Real password-reset emails via Firebase Auth

## Tech stack
- Flutter + Material 3
- Firebase (`firebase_core`, `firebase_auth`) — used for password reset
- Local mock data and repositories

## Getting started

```bash
flutter pub get
flutter run
```

Choose a device, e.g. `flutter run -d chrome`, `-d windows`, or a connected phone.

## Testing

```bash
flutter analyze
flutter test
```
